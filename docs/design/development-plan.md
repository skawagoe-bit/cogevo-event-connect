# 開発計画書

## 1. 目的
本ドキュメントは、CogEvo Event Connectの開発におけるロードマップ、タスク分解（WBS）、およびリスク管理計画を定義する。
ユーザーからのフィードバックに基づき、ギフト管理機能、リアルタイム音声文字起こし、および外部連携機能の実装を優先的に進める。

## 2. 開発ロードマップ (更新版)

### Phase 1: MVP + ギフト管理 (完了/調整中)
- **目標**: 展示会での基本フローに加え、ノベルティ在庫管理が可能であること。
- **現状**:
  - [x] インフラ構築 (Vercel, Supabase, Clerk)
  - [x] 認証機能
  - [x] 名刺スキャンUI (カメラ・音声録音)
  - [x] 訪問者リスト管理
  - [x] ギフト在庫管理機能 (v1.0実装済)
- **残タスク**:
  - [ ] ギフト機能のUI微調整
  - [ ] 訪問者登録時のRLS/認証フローの完全な安定化

### Phase 2: UX強化とAI活用 (次回優先)
- **目標**: 入力負荷の軽減とデータ精度の向上。
- **機能**:
  - **リアルタイム音声文字起こし**: 商談メモ入力時に、音声を即座にテキスト化し、その場で修正可能にする（OpenAI Whisper API または Web Speech API）。
  - **名刺OCR連携 (Sansan)**: 撮影した名刺画像からテキスト情報を自動抽出し、フォームを自動入力する。

### Phase 3: 外部エコシステム連携
- **目標**: 獲得したリード情報の活用とユーザー利便性向上。
- **機能**:
  - **LINE連携**: LINEログイン（ID連携）による会員登録・ログイン簡略化。
  - **Sansanデータ連携**: 登録データをSansanへ自動登録（タグ付け、画像送信）。
  - **UTAGE連携**: マーケティングオートメーション連携。

## 4. リスク管理計画

| リスク | 影響 | 対策 |
| :--- | :--- | :--- |
| **不安定な通信環境** | データの消失、APIエラー | IndexedDBによるローカル一時保存と、復帰時のバックグラウンド自動同期。 |
| **OCR/音声認識精度** | 誤ったデータ登録 | リアルタイムプレビューと手動修正UIの提供。音声データ自体のバックアップ保存。 |
| **API制限 (Rate Limit)** | Sansan/LINE等の制限到達 | 送信キューの導入、リトライメカニズムの実装。 |
| **デバイス互換性** | カメラ/マイク不具合 | iOS/Androidでの実機テスト徹底、フォールバック（手動入力）の用意。 |
