# プロダクト要件

## 1. プロダクト概要
### プロダクト形態
- スマートフォンアプリ（iOS / Android）

### 対応プラットフォーム
- モバイル専用（現場での機動力を重視）

## 2. コアバリュー
### このプロダクトの核となる価値
「商談直後の30秒を、成約への最短距離に変える」

### Aha Moment
- 営業：夜、1タップで数十人に完璧なパーソナライズメールが飛んだ瞬間。
- 来場者：翌日、昨日の体験（脳体力チェッカー）をもう一度自分の端末で試せた瞬間。

## 3. 主要機能

### 必須機能（Must Have）
- **イベントプリセット**: その日のイベント名、属性選択肢（医師/療法士等）の事前設定。
- **マルチ・スキャナー**: 名刺OCR、学会バッジOCR。
- **音声メールアドレス入力**: 音声認識によるメアド取得 ＋ 画面確認。
- **Sansan API 連携**: 名刺・属性・メモの自動送信。
- **UTAGE 連携**: 特定のシナリオ（ステップメール）への登録。
- **夜の一斉送信**: お礼メール ＋ 1週間限定体験URL ＋ **職種別コミュニティ招待**。
- **職種別カテゴリー・ルーム**: 属性（OT/PT/ST/医師等）に基づいた意見交換スペース。
- **ギフト消費記録**: SNS会員証提示者へのギフト提供チェック。

### 推奨機能（Should Have）
- **オフラインモード**: 電波の悪い会場でも入力を完了させ、オンライン復帰時に同期。
- **AIメモ要約**: 音声メモから重要な商談キーワードを自動抽出してSansanに送る。

## 4. 非機能要件
### パフォーマンス
- スキャンから属性選択完了までを「30秒以内」で実現する軽量なUI。

### セキュリティ
- Sansan APIキー、顧客情報の暗号化保持。
- 期間限定URLの自動失効管理。
