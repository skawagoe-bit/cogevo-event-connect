# 運用マニュアル案（営業担当者向け）

## 1. 現場での声掛け（フックの作り方）

### 名刺交換時のキラーフレーズ
> 「本日はありがとうございました。今夜、今日体験いただいた『脳体力チェッカー』を、ご自身の端末や職場のPCでも1週間だけお試しいただける特別URLをお送りします。ぜひ、明日の朝一番に職場の方にも見せてあげてください。驚かれますよ！」

### 名刺がない相手への対応
> 「名刺をお持ちでなくても大丈夫です！こちらのアプリでお名前とメールアドレスだけ頂ければ、今夜中に体験URLをお送りしますね。アドレスを読み上げていただけますか？」

## 2. アプリ運用のコツ

### 商談直後の「一言メモ」の残し方
- 文書で書こうとせず、キーワードを音声で入れる。
- 例：「〇〇病院」「OTリーダー」「予算あり」「来月デモ希望」
- これだけで、Sansan側の資産価値が劇的に上がります。

### ギフト贈呈のタイミング
- SNS会員証を提示されたら、必ず「ギフト消費」ボタンをタップ。
- これにより、「どの属性の人が、どの程度SNSに定着し、リピート来場しているか」が可視化されます。

## 3. フォローアップの黄金スケジュール

| タイミング | アクション | 目的 |
|------------|------------|------|
| 当日夜 | 本アプリから一斉送信 | 熱量を維持し、翌朝の職場報告を促す |
| 3日後 | （UTAGEから自動配信） | 脳体力チェッカーを触ってみたか確認 |
| 1週間後 | （UTAGEから自動配信） | 体験期限終了の案内 ＋ 本導入への個別相談 |

## 4. コミュニティを通じた価値向上のコツ

### ルームへの「橋渡し」トーク
- 「今日交換した皆様限定のコミュニティを作っています。特に作業療法士（OT）の方だけのルームでは、現場での効果的な使い方の裏技が共有されています。今夜招待メールを送りますね」
- 「導入後の不安や疑問も、このルームで他施設の先生に聞けるので、皆さん安心して始められていますよ」

### 意見交換の促進
- 営業マンも時折ルームに顔を出し、議論が止まっているときは「最近〇〇な事例がありました」と話題を提供。
- ユーザーから出た素晴らしい意見や活用法は、さらに「成功事例」として磨き上げ、営業資料にフィードバック。
