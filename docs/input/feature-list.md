## 機能詳細：職種別カテゴリー・ルーム
**概要：**
ユーザーの属性（職種）に合わせた専門コミュニティへ誘導し、ユーザー同士の知見共有を促進する。

**ユーザーストーリー：**
「学会でCogEvoに興味を持った作業療法士として、自分と同じように病院で導入した人の生の声を聞きたい。なぜなら、現場特有の悩みや活用法を知ることで、自分も自信を持って行動に移せるから。」

**受け入れ条件：**
- [ ] 属性データに基づき、適切なルームURLがメールに挿入されること。
- [ ] ルーム内では、ユーザー同士が気軽に意見交換できるインターフェースがあること。

## 機能詳細：トライアルURL発行
**概要：**
お礼メール内に、相手専用の「脳体力チェッカー（COG.E.V.O）」体験用URLを挿入する。

**ユーザーストーリー：**
「営業マンとして、商談の熱量を逃さず、相手が職場に戻ってから周囲にCogEvoを紹介しやすい環境を作りたい。なぜなら、98%の人が推奨するこの体験こそが最強の販促になるから。」

**受け入れ条件：**
- [ ] メール内のリンクをクリックしてから1週間（168時間）だけ有効であること。
- [ ] 誰がクリックしたかを、後で営業マンが把握できること。
