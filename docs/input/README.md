# CogEvo Event Connect（仮）

## 概要
展示会や学会の現場での「商談記録・Sansan登録・お礼メール・SNS招待」を爆速化し、商談後の1週間で「脳体力チェッカー」体験を通じてファン化・成約へ繋げる、イベント特化型セールス支援ツール。

## 解決する課題
- 大量のアクション（名刺交換、Sansan入力、メール送信、SNS招待）が手作業で、現場の営業マンの大きなストレスになっている。
- 商談の記憶が鮮明なうちにフォローができず、機会損失が発生している。
- 「こごえ棒（COG.E.V.O）」の高い体験価値（推奨率98%）が、その後の成約に十分に活かされていない。

## ターゲットユーザー
- 学会（OT/PT/ST/医師）や一般展示会に出展し、1日に数十人の来場者と商談を行う営業・開発担当者。

## 主要機能
- **爆速エントリー**: 名刺/バッジのスキャン ＋ 音声メール入力 ＋ 属性選択（医師/療法士/人事等）。
- **シームレス連携**: Sansan（顧客管理）と UTAGE（ステップメール/メルマガ）への同時自動登録。
- **体験 ＋ コミュニティ**: 夜の一斉送信メールで「脳体力チェッカー1週間限定トライアルURL」と「職種別コミュニティ」への招待を自動発行。知見共有を通じてユーザーの価値を高め、行動を促進する。
- **コミュニティ循環**: SNS会員証提示への「ギフト贈呈」記録機能。
