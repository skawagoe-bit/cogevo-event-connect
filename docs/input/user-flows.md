# ユーザーフロー

## 1. 事前準備（当日朝）
1. アプリを開き「本日のイベント設定」を行う。
2. 学会名（例：第57回日本作業療法学会）を入力。
3. 属性選択肢をセット（デフォルト：医師/PT/OT/ST/人事/営業/その他）。
4. 本日の自動送信メールのテンプレートを確認。

## 2. 現場メインフロー（商談直後）
1. 相手を見送った直後、アプリを起動。
2. 名刺をスキャン（名刺がない場合はバッジのスキャンまたはメールアドレスの音声入力）。
3. 属性をタップ。
4. 「顧客」か「協業」かを選択。
5. （必要に応じて）音声で商談内容を一言メモ。「〇〇病院、導入に前向き」など。
6. 「登録」ボタンでSansan/UTAGEへ送信。

## 3. フォローアップフロー（当日の夜）
1. 本日の登録一覧を確認。
2. 未送信のリストをチェック。
3. 「一斉送信」ボタンをタップ。
4. 全員にパーソナライズされた（属性別の）お礼メールと「脳体力チェッカー」URLが送信される。

## 4. 既存会員・ギフトフロー（ブース来訪時）
1. 既存SNS会員が来訪し「会員証（スマホ画面等）」を提示。
2. アプリの「ギフト消費」アイコンをタップ。
3. ギフトを渡し、記録完了。

## 5. 追客フロー（1週間後）
1. 「脳体力チェッカー」の1週間期限が切れるタイミングで、UTAGE経由で「いかがでしたか？」のフォローメールが自動で飛ぶ。
2. 営業担当者に、URLをクリックした「熱い」顧客のリストが通知される。
