# MVP範囲

## MVP定義

### 目的
展示会現場での入力ストレスを最小化し、商談当日の夜にお礼メール ＋ 脳体力チェッカーURLを確実に届ける仕組みを検証する。

### 対象ユーザー
自社の営業・開発担当者（少人数でテスト）。

### 成功の定義
- 展示会中の夜の事務作業時間が、従来の50%以下に短縮されること。
- 送信したURLのクリック率が20%以上を記録すること。

## スコープ

### MVP に含める ✅
| 機能 | 理由 |
|------|------|
| 名刺スキャン & 属性選択 | 最低限必要なデータ取得 |
| Sansan / UTAGE 連携 | データの蓄積とメール送信の自動化 |
| 1週間限定URLの挿入 | 成約のためのコア・フック |
| 夜の一斉送信機能 | 営業の疲労軽減に直結 |

### MVP に含めない ❌
| 機能 | 理由 | 対応時期 |
|------|------|----------|
| AIによる商談詳細要約 | 音声のテキスト化と要約の精度検証に時間がかかるため | Phase 2 |
| オフラインモード | 開発コストが高いため、まずはオンライン前提 | Phase 2 |
| 詳細なダッシュボード分析 | まずは「送る」ことに集中 | Phase 3 |

## タイムライン（目安）
- **開発フェーズ**: 1ヶ月（コア機能の構築とAPI連携テスト）
- **テストフェーズ**: 直近の学会・展示会での実戦投入
- **改善フェーズ**: 現場からのフィードバックを元に操作性を微調整
