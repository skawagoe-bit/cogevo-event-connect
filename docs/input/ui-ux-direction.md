# UI/UX方針

## 1. 全体の方向性

### デザインテーマ
「爆速（Lightning Speed） & ミス・ゼロ（Zero Error）」

### キーワード
- シンプル
- 直感的
- 片手操作
- 確信（入力できたことがはっきりわかる）

### 参考サービス
| サービス名 | 参考にする点 |
|------------|--------------|
| Sansan | OCRの精度と名刺管理の基本フロー |
| Linear | 動作の軽快さとショートカット的な操作性 |

## 2. ビジュアル

### カラー方針
- メインカラー：誠実さと先進性を感じさせるブルー（CogEvoブランドに準拠）
- アクセントカラー：重要なアクション（登録・送信）を促すオレンジまたはグリーン
- 背景：白ベースで清潔感のあるデザイン

## 3. UX原則

### 重視する体験
1. **「一瞬で終わる」**: スキャン後、数タップで登録が完了し、すぐにスマホをポケットにしまえること。
2. **「夜の解放感」**: ホテルでビールを飲みながら「送信」ボタンを押すだけで全てが終わる快感。
3. **「迷わせない」**: 現場の騒音や疲れの中でも、次に何を押せばいいか迷わない大きなボタン。

### 避けたいUX
1. 複数の確認ダイアログ（「本当によろしいですか？」の連発）。
2. 小さい文字入力エリア（現場ではキーボード入力は最小限に）。

## 4. 画面構成

### 主要画面一覧
| 画面名 | 目的 | 主要要素 |
|--------|------|----------|
| プリセット画面 | 朝の設定 | イベント名入力、属性マスタ選択 |
| スキャン・入力画面 | 現場での記録 | カメラプレビュー、属性ボタン、音声録音アイコン |
| 本日のリスト画面 | 夜の確認 | 本日の登録者一覧、ステータス（未送信/送信済） |
| 一斉送信確認 | 最終チェック | 送信件数表示、テンプレート確認、送信ボタン |

### 画面遷移図
```
[プリセット] → [スキャン] → [属性選択] → [登録完了]
                  ↓
           [本日のリスト] → [一斉送信確認] → [完了]
```
