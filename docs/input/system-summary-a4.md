# 【A4一枚まとめ】CogEvo Event Connect 概要

## 1. プロジェクトの目的
展示会・学会での「商談」を、営業担当者の負担を最小限に抑えつつ、最速で「成約」へと繋げる。
名刺交換後の事務作業を自動化し、98%が推奨する「脳体力チェッカー」の体験をフックにしたファン化を促進する。

## 2. 解決する3つの課題
1.  **現場の疲弊**: 1日数十件のSansan入力とメール送信が、営業マンの大きなストレス。
2.  **フォローの遅延**: 商談の熱量が下がる前に、適切なアプローチができていない。
3.  **体験の断絶**: 現場で感動した「こごえ棒」の体験が、職場（導入検討現場）に持ち帰られていない。

## 3. 主要機能とソリューション
### ① 爆速エントリー（入力ストレスの解消）
- **OCRスキャン**: 名刺だけでなく、学会バッジからも即座に情報を取得。
- **属性ワンタップ**: 医師/療法士/人事など、当日のターゲットに合わせた属性を1秒で選択。
- **音声メール入力**: 名刺がない相手でも、声に出してもらうだけでメアド登録。

### ② シームレス連携（事務作業のゼロ化）
- **Sansan自動同期**: 入力と同時に名刺データと商談属性を全社資産として登録。
- **UTAGE自動登録**: 即座にステップメールの配信リストへ追加。

### ③ 体験型フォロー ＆ 職種別コミュニティ（価値向上と行動促進）
- **夜の一斉送信**: 脳体力チェッカーの「1週間限定URL」を自動配信し、即時体験を提供。
- **職種別ルームへの招待**: OT/PT/ST、医師、人事など、属性に応じた専門コミュニティ（ルーム）へ案内。
- **知見共有と行動変容**: 専門職同士が「どう活用しているか」を意見交換することで、プロダクトの価値を最大化し、実際の現場導入や活用行動へと繋げる。

## 4. 運用フロー（4ステップ）
1.  **【現場】**: 商談直後に30秒でスキャン＆属性選択。
2.  **【夜間】**: ホテル等で1タップし、お礼メールと「体験URL」「コミュニティ招待」を送信。
3.  **【継続】**: コミュニティ内での意見交換を通じて、プロダクトの深い理解と活用が進む。
4.  **【成果】**: 1週間後、体験とコミュニティの熱量を持った「質の高い」見込み客へアプローチ。

## 5. 期待される効果
- **時間削減**: 展示会後の事務作業時間を50%以上削減。
- **接点強化**: 全ての来場者に対し、当日中にパーソナライズされた体験（CogEvo）を提供。
- **成約加速**: 「面白い」という体験が熱いうちに職場へ波及し、導入検討のスピードが上がる。
