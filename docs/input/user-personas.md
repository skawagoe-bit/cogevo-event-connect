# ターゲットユーザー

## メインペルソナ：現場の営業・開発担当者

### 基本情報
- 職業：医療機器・ヘルスケアサービス企業の営業、新規事業担当
- 生活環境：学会や展示会で全国を飛び回る。現場では1人でブースを切り盛りすることもある。

### 課題・ペイン
- 商談が終わった後、すぐに次の来客があり、メモを書く暇がない。
- 夜、ホテルに戻ってから行う数十件のメール送信が精神的・体力的に辛い。
- せっかく「こごえ棒」を体験して感動してくれたのに、その後のフォローが遅れて熱量が下がってしまう。

### このプロダクトを使う瞬間
- 学会ブースで商談が終わり、相手を見送った直後の30秒間。
- 全ての展示が終了し、帰りの電車やホテルで1日の成果を確認する瞬間。

---

### 接点となる相手（来場者属性）
1. **医療専門職（OT/PT/ST、医師）**: 現場での導入メリット、エビデンスを重視。脳体力チェッカーの体験に高い関心。
2. **企業担当者（人事、新規事業、営業）**: 従業員の健康管理や自社サービスとの連携を模索。
3. **パートナー候補**: 販売代理店や共同研究の可能性を探る人々。

---

## 非ターゲット
- 名刺交換が1日3件以下など、手動管理で十分間に合っている人。
- 顧客との長長期的な関係構築を必要としない、売り切り型の商材を扱う人。
