# Obsidian連携 設定手順

来場者編集画面から、Obsidianに直接メモを作成できます。

## 1. 事前準備

1. 連携先デバイスに Obsidian をインストールします。
2. 連携したい Vault 名を確認します（正確な表記が必要です）。

## 2. アプリ側の設定

1. 本アプリの **プロフィール設定** を開きます。
2. **Obsidian連携** セクションで以下を設定します。
   - **Vault名（必須）**
   - **保存フォルダ（任意）**  
     例: `CRM/Visitors`
3. 保存します。

## 3. 来場者メモを Obsidian に送る

1. 来場者リストから対象を開き、編集画面へ移動します。
2. **Obsidianに保存** ボタンを押します。
3. Obsidian が起動し、新規ノートが作成されます。

## 4. 作成されるノート内容

- イベント名
- 会社名 / 氏名 / メール
- 属性 / 区分
- 訪問日
- 商談メモ

ファイル名は次の形式です:

`YYYY-MM-DD_会社名_氏名`

## トラブルシュート

- **Obsidianが起動しない**
  - OS 側で `obsidian://` スキームが許可されているか確認してください。
  - ブラウザの外部アプリ起動許可ダイアログを確認してください。
- **Vaultが見つからない**
  - プロフィール設定の Vault 名が Obsidian 側と一致しているか確認してください。
